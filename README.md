# Smart AI-Based Restricted Area Intrusion Detection

## Project Overview
This project detects possible human movement in restricted areas using simulated Wi-Fi Channel State Information (CSI) data and an AI model.

## Features
- Simulated Wi-Fi CSI graph
- Movement detection
- AI-based prediction: NORMAL or SUSPICIOUS
- Restricted area selection
- Intrusion alert log
- Alert popup and sound
- Web-based dashboard

## Technologies Used
- Python
- Flask
- Machine Learning
- HTML and CSS
- Matplotlib
- Simulated Wi-Fi CSI data

## Current Status
The software demo is deployed and tested on Render. The current version uses simulated CSI data.

## Future Scope
- ESP32 hardware integration
- Real Wi-Fi CSI data collection
- Real-time movement detection
- Hardware-based intrusion alerts
